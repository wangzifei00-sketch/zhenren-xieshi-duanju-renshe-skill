# 生成后质检与返修

## 检查顺序

先看整图，再放大头像和局部；依次检查规格、视角、身份、解剖、光线和材质。记录“通过／需修／不可确认”，不要把看不清当成通过。若输出不足以辨认皮肤微纹理，应标记不可确认，不靠锐化或添加颗粒伪造细节。

| 项目 | 可观察的合格条件 | 常见问题与定向修正 |
|---|---|---|
| 文件规格 | 读取真实宽高；16:9满足9W=16H；无拉伸 | 近似比例注明偏差；用留白调整画布，勿裁头脚 |
| 四列顺序 | 头像、全身正面、左侧面、背面各一幅且一行排列 | 错栏、串栏或重复视图：重做相关列或分别生成后合成 |
| 角度 | 侧面看到角色左侧且鼻尖朝画面左；背面不回头 | 不用镜像整张图修复，否则左右配饰会反转 |
| 尺度与完整性 | 后三列同尺度、头顶脚底对齐、头脚完整；头像允许放大 | 调整排版与裁切范围，不压扁或拉长人物 |
| 8头身 | 可辨颅顶至脚底／颅顶至下巴约为8；不计发髻与鞋跟 | 先辨解剖位置再评估；不要凭发饰总高测量 |
| 3:7 | 颅顶到视觉腰线占身高约30%；高腰衣装分割自然 | 这是视觉腰线，不是骨盆位置；通过服装修正，不拉长腿骨 |
| 身份 | 头像与正面脸部比例吻合；侧脸鼻额下颌可解释；后脑发型一致 | 优先沿用同一参考修正面部和发型，不全图重新随机化 |
| 左右与配饰 | 玉簪、结扣、衣襟等在角色身体上的位置不变 | 检查可见、遮挡、转向逻辑；允许侧面被遮住 |
| 解剖 | 手脚、关节、肩髋、身体重心自然，衣下体积成立 | 优先局部修复；长裙遮挡时标记腿部比例不可确认 |
| 皮肤 | 头像可见细微且随区域变化的纹理、唇纹、肤色起伏 | 蜡像感：减磨皮、加局部自然差异；砂纸感：降低颗粒与锐化 |
| 摄影 | 透视自然、细节可辨，无明显广角变形或虚假锐化边缘 | 统一机位观感、减少浅景深、保留真实细节尺度 |
| 光线 | 同一棚灯逻辑；肤色曝光一致；白衣仍有边界 | 用统一曝光、白平衡和背景光修正，不把皮肤一起漂白 |
| 布料 | 材质反光有区别，褶皱与受力重力吻合，接缝层次合理 | 塑料感：区分粗糙度与厚度；漂浮褶皱：回到肩肘腰带受力 |
| 白底 | 无额外元素、地平线和背景地面投影；人物保留体积 | 若要求数值纯白，采样远离人物的区域应为RGB 255/255/255；边缘允许抗锯齿过渡 |

## 比例的测量边界

有足够清晰的正面图时，可记 H=颅顶至脚底像素高度、h=颅顶至下巴高度、u=颅顶至视觉腰线高度，检查 H/h≈8、u/H≈0.30。目测或衣物遮挡无法精确确定时注明估计，不填虚构数值。

内部初筛可暂用7.7–8.3头身、视觉腰线高度占比0.28–0.32作为宽容区间；这是本模板的工作容差，不是行业标准。用户要求更严格时应事先明确测量定义，并以自然解剖为约束。背面看不到下巴时不要独立硬算头长，使用一致尺度辅助比较。

## 返修优先级与停止条件

- 必修：缺列、错角度、身份明显不一致、明显解剖错误、裁切头脚、比例或白底等明确要求未满足。
- 次级修正：皮肤过塑、衣料失真、轻微色温差、局部发丝与边缘问题。先确认这些细节在最终尺寸上确实可见。
- 每次仅针对明确问题修订，再复查身份和布局是否退化。首次生成后默认最多两轮定向返修；超过轮次仍未通过时标记“未通过／部分通过”并列出残留项，不称为最终合格图。
