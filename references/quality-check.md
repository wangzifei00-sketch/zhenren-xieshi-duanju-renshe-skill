# 生成后质检与返修

## 检查顺序

先读取本次任务规格。下表是检查项目库，其中四列、16:9、8头身、视觉3:7和白底等条件仅在本次启用时适用；用户覆盖默认值时，将对应合格条件替换为本次要求，例如灰底按灰底要求检查。未启用或与交付范围无关的项目标记“不适用”并说明原因，不计为缺陷；已要求但看不清的项目仍是“不可确认”，不能改成“不适用”。缺少原始规格时注明无法确认要求，不自行套用默认验收条件。

先看整图，再放大头像和局部；依次检查规格、视角、身份、解剖、光线和材质。记录“通过／需修／不可确认／不适用”，不要把看不清当成通过。若输出不足以辨认皮肤微纹理，应标记不可确认，不靠锐化或添加颗粒伪造细节。

| 项目 | 可观察的合格条件 | 常见问题与定向修正 |
|---|---|---|
| 文件规格 | 读取真实宽高；16:9满足9W=16H；无拉伸 | 近似比例注明偏差；用留白调整画布，勿裁头脚 |
| 四列顺序 | 头像、全身正面、左侧面、背面各一幅且一行排列 | 错栏、串栏或重复视图：重做相关列或分别生成后合成 |
| 角度 | 侧面看到角色左侧且鼻尖朝画面左；背面不回头 | 不用镜像整张图修复，否则左右配饰会反转 |
| 尺度与完整性 | 后三列同尺度、头顶脚底对齐、头脚完整；头像允许放大 | 调整排版与裁切范围，不压扁或拉长人物 |
| 8头身 | 可辨颅顶至脚底／颅顶至下巴约为8；不计发髻与鞋跟 | 先辨解剖位置再评估；不要凭发饰总高测量 |
| 3:7 | 颅顶到视觉腰线占身高约30%；高腰衣装分割自然 | 这是视觉腰线，不是骨盆位置；通过服装修正，不拉长腿骨 |
| 身份 | 头像与正面脸部比例吻合；侧脸鼻额下颌可解释；后脑发型一致 | 优先沿用同一参考修正面部和发型，不全图重新随机化 |
| 左右与配饰 | 玉簪、结扣、衣襟等在角色身体上的位置不变 | 检查可见、遮挡、转向逻辑；允许侧面被遮住 |
| 解剖 | 手脚、关节、肩髋、身体重心自然，衣下体积成立 | 优先局部修复；长裙遮挡时标记腿部比例不可确认 |
| 皮肤 | 头像可见细微且随区域变化的纹理、唇纹、肤色起伏 | 蜡像感：减磨皮、加局部自然差异；砂纸感：降低颗粒与锐化 |
| 摄影 | 透视自然、细节可辨，无明显广角变形或虚假锐化边缘 | 统一机位观感、减少浅景深、保留真实细节尺度 |
| 光线 | 同一棚灯逻辑；肤色曝光一致；白衣仍有边界 | 用统一曝光、白平衡和背景光修正，不把皮肤一起漂白 |
| 布料 | 材质反光有区别，褶皱与受力重力吻合，接缝层次合理 | 塑料感：区分粗糙度与厚度；漂浮褶皱：回到肩肘腰带受力 |
| 白底 | 无额外元素、地平线和背景地面投影；人物保留体积 | 若要求数值纯白，采样远离人物的区域应为RGB 255/255/255；边缘允许抗锯齿过渡 |

## 身份基准核对

先核对本轮角色卡、基准图和输出图的版本关联，再比较输出与身份基准中的脸部锚点；多视图还须相互比较。不能用待检图自身证明它符合此前身份，也不能仅凭图像版本号认定一致。初次原创候选先对照文字角色卡选择工作基准，记录这一证据边界；后续视图对照该基准检查。

只有文字设定而无图像基准时，可检查文字符合度与图内跨视图一致性，但不得声称已验证对某张参考的身份保真。任务要求保持指定参考身份而参考不可访问或不可辨时，对应项为不可确认。仅服装参考的人脸不参与身份判定。

对不可见部位分别记录“符合已采用的补全设计”和“可由原参考验证”，不要混为同一结论。角色卡变更后逐一核对关联视图；旧图中锁定项与新设定明确冲突时为需修，尚未复查时为未检查。换基准不得用于消除已经发现的身份漂移。

## 比例的测量边界

仅在本次启用相应比例要求且有足够清晰的正面图时，可记 H=颅顶至脚底像素高度、h=颅顶至下巴高度、u=颅顶至视觉腰线高度，检查 H/h≈8、u/H≈0.30。目测或衣物遮挡无法精确确定时注明估计，不填虚构数值。

内部初筛可暂用7.7–8.3头身、视觉腰线高度占比0.28–0.32作为宽容区间；这是本模板的工作容差，不是行业标准。用户要求更严格时应事先明确测量定义，并以自然解剖为约束。背面看不到下巴时不要独立硬算头长，使用一致尺度辅助比较。

## 拆视图与合成检查

- 合成前：逐图核对角色卡、基准及图片版本，检查唯一视角、构图完整性、身份、解剖与适用材质要求。单图没有其他视角不构成“缺列”；整板布局、列间对齐和跨视图一致性留到对应阶段检查，不能因此从最终任务中删除。
- 所有单图适用检查通过，并且合成前跨视图比较的身份、服装、配饰、机位与灯光逻辑一致后，才进入正式合成。输入存在需修、不可确认或未检查项时，保留相应状态并优先处理；预算耗尽则交付当前素材及问题，不把拼成一张图当作问题已解决。
- 合成后：核对真实尺寸、顺序、间隔、全身尺度及头脚对齐、头像独立尺度、边缘和背景；复查身份、左右配饰、肤色曝光与服装颜色，并在最终尺寸检查细节可辨度。单图通过不能代替成图通过，缩放后皮肤细节不足仍记不可确认。
- 当工具无法合成且整板是必需交付物时，独立视图可有各自的通过记录，但整板缺失按总体结论规则记未通过，并注明“独立视图已交付，整板待合成”。若用户原本只要求独立视图，则合成不适用。

## 总体结论

先按本次任务规格列出必验项（必须满足项对应的检查），再逐项记录状态与依据。不得在检查失败后将必验项降为建议项。“不适用”不参与汇总；“不可确认”不是通过，也不是已证实失败。

按以下顺序汇总，命中前项即采用该结论：

| 条件 | 总体结论 |
|---|---|
| 尚未生成图片 | 尚未生成待检 |
| 已有图片但未实际查看 | 未查看待检 |
| 已查看，任一必验项为需修（包括明确要求的视图或文件缺失） | 未通过 |
| 无必验项明确失败，但存在必验项不可确认、尚未检查，或原始要求不足以确定必验范围 | 部分通过；列出证据缺口，不表示已获验收 |
| 必验项全部通过，但其他适用检查仍有需修、不可确认或未检查项 | 部分通过；区分必验项已通过与其余残留项 |
| 必验范围明确且非空，所有适用检查均通过 | 通过 |

没有任何已证实通过项时，“部分通过”仍须明确写出“目前无已确认通过项”，不能暗示已有合格成果。仅查看了部分视图时，未查看视图记为未检查；已经确认缺失的必需视图记为需修。

例如：身份漂移且皮肤不可确认，判未通过；身份等必验项通过但要求的皮肤纹理看不清，判部分通过；单头像任务的全身比例不适用，不阻碍其他适用项全部通过后的总体通过。

## 返修优先级与停止条件

- 必修（仅限本次适用要求）：缺列、错角度、身份明显不一致、明显解剖错误、裁切头脚、比例或白底等明确要求未满足。
- 次级修正：皮肤过塑、衣料失真、轻微色温差、局部发丝与边缘问题。先确认这些细节在最终尺寸上确实可见。
- 每次仅针对明确问题修订。返修前保留输入图及其质检记录，输出另存版本，不覆盖上一版；记录本轮目标与保留项。
- 返修后先检查目标缺陷，再复查全部适用必验项，并检查其他区域、相邻边界是否退化。不能因为提示词要求“只改局部”就沿用旧版通过结论；未能复查的项标记未检查，按上表汇总。
- 新版使已通过的必验项退化时，不自动替换当前最佳版本。保留前后版本并记录差异；优先选择身份、解剖、布局等必修问题更少且未引入更严重问题的版本作为后续输入。无法判断优劣时保留候选并说明取舍，不能声称新版更好。
- 首次生成后默认最多两轮定向返修，用户另有预算或轮数时遵循用户要求。达到上限后停止生成，交付有记录支持的最佳可用版本及该版本的实际结论、残留项；不默认交付最后一版，不因达到轮数上限而改变验收标准。回退不重置已消耗的返修轮次。
