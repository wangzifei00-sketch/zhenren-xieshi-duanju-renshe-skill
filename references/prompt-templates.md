# 角色锁定卡与提示词模板

## 使用方式

花括号字段是填写槽位，不是待完成的 Skill 内容。执行前填写或删除；用户未指定的内容采用合理默认并简要披露。共享身份段应在每个视图请求中保持原文一致。

## 角色锁定卡

```text

参考依据：{已查看的图片／用户文字／原创设定}

脸部锚点：{脸型、眉形、眼距、鼻梁鼻尖、唇形、下颌}

头发与配饰：{发际线、分缝、发髻结构、饰品及身体左右侧}
身体与比例：{体态；默认8头身、视觉高腰3:7}
服装结构：{内外层、领型、开合、袖型、腰带、下摆、鞋履}

```

## 通用主提示词

```text
制作真人影视风格角色摄影参考板，呈现真实成年演员穿着可实际制作的服装。

身份锁定：{填入角色卡中的固定身份与服装描述}。四幅是同一人的不同观察视图，同一年龄、五官结构、肤色、发型、服装与配饰，不是四个相似的人。

横向16:9白色画布，一行四列，按画面从左至右固定为：①正视头像特写，完整发型至肩部；②正面全身0°；③角色自身左侧全身90°，看见左脸，鼻尖朝画面左方；④背面全身180°，头朝正后方。列间留白，不显示编号、文字或边框。后三列头顶和脚底对齐，人物等高且完整入画，头像单独放大。

自然直立，中性表情，手臂略离躯干，手指放松，衣袖不遮挡主要结构。身体约8头身，头长按颅顶至下巴计算，排除发饰；高腰服装形成颅顶至视觉腰线、腰线至脚底约3:7的视觉分割，保持正常髋膝位置和自然人体结构。

真实摄影的自然透视，平视与适当拍摄距离，约85毫米全画幅人像镜头观感，后三视图同一机位尺度，足够景深，细节清楚而不过度锐化。大面积柔光从摄影机左前上方照射，弱补光，统一白平衡与曝光；人物转身，棚灯位置保持固定。

皮肤有细腻但非均匀的毛孔、轻微肤色变化、自然唇纹、少量细软绒毛与微小左右差异；全身视图不夸大毛孔。头发有自然发丝分组与少量碎发，眼睛有合理眼睑厚度和柔和反光。

服装材质：{逐层材质及其光泽、厚度、褶皱行为}。褶皱符合肩肘与腰带受力、衣摆重力，刺绣贴合布面，接缝和层次连贯。发饰与服装不对称结构按角色身体左右侧随转身变化。

背景为纯白纯色，无地平线、地面投影或背景阴影。人物自身保留柔和体积明暗、衣褶遮蔽和真实材质反射，浅色衣料与白底之间边缘清晰。

限制：{从下方负面约束中保留与任务相关的项目}。
```

## 可直接使用的亚洲古风成年女性示例

以下为原创默认设计，并非对原对话未能读取的图片进行复原。可将这一段直接填入通用提示词的“身份锁定”和“服装材质”位置。

```text
同一位约26岁的亚洲古风成年女性，仪态端正，神情平静。偏鹅蛋脸，柔和且清晰的下颌，平直略弯的自然眉，深棕眼睛，适中的眼距，鼻梁自然挺直、鼻尖圆润，唇形清楚但不夸张。暖中性浅肤色，保留颊部轻微血色及细腻皮肤纹理，低覆盖自然淡妆，不使用磨皮滤镜。

黑色长发中分，后上方盘成结构清楚的发髻，余发顺背垂下；一枚哑光玉簪插在角色自身左侧，不佩戴耳饰。每个视图保持同样的发际线、发髻体积与玉簪位置。

米白色交领内衣，外穿低饱和浅青色丝质长衫，领口在角色右侧闭合，袖形舒展但不遮住手。深青色织物腰带系在高腰，结位于角色自身右侧；米白色长裙自然下垂，露出浅色平底布鞋鞋尖。无手持道具。属于原创古风服装设计，不指定历史朝代。

外衫有丝绸柔和的方向性反光与顺重力垂落的细褶，内衣和长裙为偏哑光的棉质织物，有克制的细密织纹，腰带较厚实。领口少量同色刺绣贴附布面，不发光，不形成漂浮的金属花纹。
```

## 负面约束库

优先排除已出现的错误，避免无限加词。无需把痣、雀斑或正常肤色变化一概排除，也不要用“无瑕皮肤”抵消真实纹理。

```text
无动漫、插画、游戏CG、蜡像、塑料皮肤、过度磨皮、均匀颗粒毛孔、油亮面具、过度HDR、锐化光晕、假睫毛团块；无广角畸变、大头短腿、超长四肢、异常腰髋、畸形手指、额外肢体、衣物穿模、悬浮衣摆；无身份漂移、五官换脸、发型变化、服装换色、配饰增减或左右镜像错误；无四分之三侧身冒充左侧面、背面回头、重复正面、缺少视图、多行布局、串栏、裁头裁脚；无场景、文字、水印、边框、地平线、背景渐变、背景或地面投影。
```
