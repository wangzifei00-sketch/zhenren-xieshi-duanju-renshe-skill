# 角色锁定卡与提示词模板

## 使用方式

花括号字段是填写槽位，不是待完成的 Skill 内容。执行前填写或删除；用户未指定的内容采用合理默认并简要披露。共享身份段应在每个视图请求中保持原文一致。

## 本次任务规格

默认值及比例、视角定义统一见 [SKILL.md](../SKILL.md) 的“本 Skill 的默认版式”。先根据用户要求填写本表，再生成提示词，不把下方槽位留在交付文本中。

```text
工作模式：{仅提示词／参考图编辑／生成／质检}
视图与顺序：{仅列本次需要的视图、角度、朝向与构图范围}
布局与画布：{排列、画布比例、对齐规则；不适用的规则删除}
姿势与表情：{按视图填写}
身体比例：{启用的定义与要求／不适用／用户未要求约束}
背景：{颜色、场景、投影与人物明暗要求}
必须满足项：{来自本次要求及适用默认值的验收条件}
采用的默认项：{列出实际采用的项目}
不适用项：{项目与原因；不得进入生成约束}
```

例如“仅头像、灰底、不要求8头身”：只输出头像；背景为灰色；全身比例、四列布局、头脚完整性和多视图对齐不适用，白底也不是验收条件。画布比例如未指定，可以采用主文件默认值并披露。

## 通用主提示词

```text
制作真人影视风格角色摄影参考板，呈现真实成年演员穿着可实际制作的服装。

身份锁定：{填入角色卡中的固定身份与服装描述}。{仅多视图时加入：各视图是同一人，同一年龄、五官结构、肤色、发型、服装与配饰。}

画面与视角：{根据本次任务规格写入画布、布局、视图顺序、角度、构图范围及适用的尺度对齐规则}。

姿势、表情与比例：{写入本次启用的姿势与比例定义；不适用时删除对应约束，不加入全身或多视图要求}。保持自然人体结构，不以拉伸肢体或缩小头部强凑比例。

真实摄影的自然透视，平视与适当拍摄距离，约85毫米全画幅人像镜头观感，{仅多视图时加入：全身视图保持同一机位尺度}，足够景深，细节清楚而不过度锐化。大面积柔光从摄影机左前上方照射，弱补光，统一白平衡与曝光；{仅多视图时加入：人物转身，棚灯位置保持固定}。

皮肤有细腻但非均匀的毛孔、轻微肤色变化、自然唇纹、少量细软绒毛与微小左右差异；全身视图不夸大毛孔。头发有自然发丝分组与少量碎发，眼睛有合理眼睑厚度和柔和反光。

服装材质：{逐层材质及其光泽、厚度、褶皱行为}。褶皱符合肩肘与腰带受力、衣摆重力，刺绣贴合布面，接缝和层次连贯。发饰与服装不对称结构按角色身体左右侧随转身变化。

背景：{写入本次背景颜色、场景与投影要求}。人物自身保留柔和体积明暗、衣褶遮蔽和真实材质反射，人物与背景之间边缘清晰。

限制：{从下方负面约束中保留与任务相关的项目}。
```

## 可直接使用的亚洲古风成年女性示例

以下为原创默认设计，并非对原对话未能读取的图片进行复原。可将这一段直接填入通用提示词的“身份锁定”和“服装材质”位置。

```text
同一位约26岁的亚洲古风成年女性，仪态端正，神情平静。偏鹅蛋脸，柔和且清晰的下颌，平直略弯的自然眉，深棕眼睛，适中的眼距，鼻梁自然挺直、鼻尖圆润，唇形清楚但不夸张。暖中性浅肤色，保留颊部轻微血色及细腻皮肤纹理，低覆盖自然淡妆，不使用磨皮滤镜。

黑色长发中分，后上方盘成结构清楚的发髻，余发顺背垂下；一枚哑光玉簪插在角色自身左侧，不佩戴耳饰。每个视图保持同样的发际线、发髻体积与玉簪位置。

米白色交领内衣，外穿低饱和浅青色丝质长衫，领口在角色右侧闭合，袖形舒展但不遮住手。深青色织物腰带系在高腰，结位于角色自身右侧；米白色长裙自然下垂，露出浅色平底布鞋鞋尖。无手持道具。属于原创古风服装设计，不指定历史朝代。

外衫有丝绸柔和的方向性反光与顺重力垂落的细褶，内衣和长裙为偏哑光的棉质织物，有克制的细密织纹，腰带较厚实。领口少量同色刺绣贴附布面，不发光，不形成漂浮的金属花纹。
```

## 负面约束库

按本次任务规格筛选，未启用的布局、视角、背景约束必须删除；例如灰底任务不加入“无背景渐变”等未经要求的限制，单头像任务不加入“缺少视图、裁脚”。优先排除已出现的错误，避免无限加词。无需把痣、雀斑或正常肤色变化一概排除，也不要用“无瑕皮肤”抵消真实纹理。

```text
无动漫、插画、游戏CG、蜡像、塑料皮肤、过度磨皮、均匀颗粒毛孔、油亮面具、过度HDR、锐化光晕、假睫毛团块；无广角畸变、大头短腿、超长四肢、异常腰髋、畸形手指、额外肢体、衣物穿模、悬浮衣摆；无身份漂移、五官换脸、发型变化、服装换色、配饰增减或左右镜像错误；无四分之三侧身冒充左侧面、背面回头、重复正面、缺少视图、多行布局、串栏、裁头裁脚；无场景、文字、水印、边框、地平线、背景渐变、背景或地面投影。
```

## 定向返修模板

```text
以当前图片和同一身份参考为基础，只修正{具体列与缺陷}。
维持已通过的{脸部锚点、发型、服装、颜色、构图、其他视图}。
修正后的可观察目标：{例如第三列展示角色自身左侧，鼻尖朝画面左方，肩髋严格侧向，脚底仍与第二、四列对齐}。
不要通过{例如镜像整图、拉伸身体、全局磨皮}实现修正。
修正后先检查目标缺陷，再复查全部适用必验项，以及其他区域、配饰身体左右侧和相邻边界是否退化。
```

执行返修时保留输入、输出和各自质检记录，按 [质检与返修](quality-check.md) 的总体结论与版本选择规则决定保留或回退；提示词中的保留指令不能代替实际复查。

若只提供文本而未执行，附一句“这是生成方案，图像效果与质检结论待实际生成后确认”。
