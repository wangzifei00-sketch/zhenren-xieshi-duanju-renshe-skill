# 角色锁定卡与提示词模板

## 使用方式

花括号字段是填写槽位，不是待完成的 Skill 内容。执行前填写或删除；用户未指定的内容采用合理默认并简要披露。共享身份段应在每个视图请求中保持原文一致。

## 本次任务规格

默认值及比例、视角定义统一见 [SKILL.md](../SKILL.md) 的“本 Skill 的默认版式”。先根据用户要求填写本表，再生成提示词，不把下方槽位留在交付文本中。

```text
工作模式：{仅提示词／参考图编辑／生成／质检}
视图与顺序：{仅列本次需要的视图、角度、朝向与构图范围}
布局与画布：{排列、画布比例、对齐规则；不适用的规则删除}
姿势与表情：{按视图填写}
身体比例：{启用的定义与要求／不适用／用户未要求约束}
背景：{颜色、场景、投影与人物明暗要求}
必须满足项：{来自本次要求及适用默认值的验收条件}
采用的默认项：{列出实际采用的项目}
不适用项：{项目与原因；不得进入生成约束}
```

例如“仅头像、灰底、不要求8头身”：只输出头像；背景为灰色；全身比例、四列布局、头脚完整性和多视图对齐不适用，白底也不是验收条件。画布比例如未指定，可以采用主文件默认值并披露。

## 本轮版本关联

以下为执行记录，不作为画面内文字。图片引用必须能够定位实际文件或工具结果，不能只写“上一张”。

```text
本轮角色卡：{角色编号＋角色卡版本}
本轮身份基准：{图像引用＋基准版本／未建立}
输入图：{文件引用＋图片版本；首次生成写无}
输出图与视图：{实际文件引用＋图片版本＋视图名称；未生成写待生成}
对应质检：{该输出版本的记录引用或随附记录}
待重新检查的关联视图：{角色设定变化影响的视图与项目／无}
```

提交工具时实际附上可用的基准图和所需参考，并在提示词中说明各图用途。仅写文件名或版本号不会自动给工具提供图像；工具不支持图像参考时如实说明只能用文字近似，不能宣称已实现图像身份锁定。

## 通用主提示词

```text
制作真人影视风格角色摄影参考板，呈现真实成年演员穿着可实际制作的服装。

参考分工：{实际提供给工具的各图及用途；无参考时删除此段}。

身份锁定：{填入本轮角色卡版本中的固定身份与服装描述}。{仅多视图时加入：各视图是同一人，同一年龄、五官结构、肤色、发型、服装与配饰。}

画面与视角：{根据本次任务规格写入画布、布局、视图顺序、角度、构图范围及适用的尺度对齐规则}。

姿势、表情与比例：{写入本次启用的姿势与比例定义；不适用时删除对应约束，不加入全身或多视图要求}。保持自然人体结构，不以拉伸肢体或缩小头部强凑比例。

真实摄影的自然透视，平视与适当拍摄距离，约85毫米全画幅人像镜头观感，{仅多视图时加入：全身视图保持同一机位尺度}，足够景深，细节清楚而不过度锐化。大面积柔光从摄影机左前上方照射，弱补光，统一白平衡与曝光；{仅多视图时加入：人物转身，棚灯位置保持固定}。

皮肤有细腻但非均匀的毛孔、轻微肤色变化、自然唇纹、少量细软绒毛与微小左右差异；全身视图不夸大毛孔。头发有自然发丝分组与少量碎发，眼睛有合理眼睑厚度和柔和反光。

服装材质：{逐层材质及其光泽、厚度、褶皱行为}。褶皱符合肩肘与腰带受力、衣摆重力，刺绣贴合布面，接缝和层次连贯。发饰与服装不对称结构按角色身体左右侧随转身变化。

背景：{写入本次背景颜色、场景与投影要求}。人物自身保留柔和体积明暗、衣褶遮蔽和真实材质反射，人物与背景之间边缘清晰。

限制：{从下方负面约束中保留与任务相关的项目}。
```

## 单视图生成模板

用于独立视图任务，或整板失败后只重做有问题的视图。先选定一个目标视图，填写共享段与该视图要求；不要同时复制通用模板中的整板布局。身份、服装、材质和棚灯共享段在各次请求中保持一致，仅改变视角、构图及合理可见内容。实际附上本轮身份基准和需要的参考，记录本轮版本关联。

```text
生成一幅真人影视风格角色摄影参考图，画面中仅一个人物、一个目标视图，不生成拼图、额外头像或其他角度。

参考分工：{实际附带的图及各自用途；无图时删除}。
共享身份与服装：{从本轮角色卡复制固定描述，包含发饰与结扣的身体左右侧；不得逐视图改写身份}。

唯一目标视图：{视图名称、严格角度、朝向、可见部位与构图范围}。
姿势与比例：{本视图适用的本次任务要求；头像删除全身比例与姿势约束}。
单图画布与留边：{工具支持的单图比例或尺寸、完整入画范围、合成所需留白；不机械沿用整板画布比例}。

共享摄影与棚灯：{本次确定的机位观感、光位、白平衡、曝光和景深；全身各视图保持同一机位高度与距离观感}。人物转动，灯位相对摄影机保持固定，受光部位随转向自然变化。
共享材质：{逐层材质与物理行为；按本视图尺度呈现皮肤、发丝和衣料细节}。
背景：{本次背景要求，与拟合成画布一致}。

保持身份、服装结构与不对称配饰位置。只呈现该角度合理可见的内容，不强行露出被遮挡的配饰，不用镜像生成另一侧。不可见部位按角色卡已采用的补全设计呈现。
限制：{仅保留本视图适用的负面约束，不带入多列或其他视图要求}。
```

默认视图的角度与构图定义沿用主文件；目标为左侧面时只填写左侧面，不将正面、头像和背面要求一起送入工具。用户指定其他视图时按其要求填写。

## 合成规格单

仅在任务需要整板时填写。保留已通过且可完整分离的视图，重新生成失败视图；不能从串栏、遮挡或裁切残缺的区域强行截取合格素材。合成前检查各输入图及其跨视图一致性，具体准入与成图复查见 [质检与返修](quality-check.md)。

```text
角色卡与身份基准：{角色编号＋角色卡版本；基准引用＋版本}
输入清单：{逐项写视图名称、文件引用、图片版本、实际宽高、质检记录}
目标画布：{本次要求的比例；实际可输出的宽×高；背景}
排列：{本次视图顺序、各区域尺寸、间隔与外边距}
全身对齐：{共同的头顶线、脚底线和人物高度；单图等比缩放后平移定位}
头像区域：{独立缩放与裁切范围；保留本次要求的完整发型等内容}
允许处理：{等比缩放、平移、空白区域裁切或扩展；必要的轻微曝光与白平衡调整}
禁止处理：{拉伸或压缩人体、镜像纠正朝向、裁掉所需头脚、改变脸部锚点或服装结构}
输出：{新文件引用与图片版本；保留源图}
成图质检：{按最终尺寸检查的记录与结论；未合成写待合成}
```

全身对齐时使用一致的人体位置作为依据，发髻与饰物保留在留边内；不能靠拉伸解决姿势、透视或人体比例差异。等比缩放和平移仍无法同时满足头脚对齐时，回到问题视图修正。头像不套用全身缩放尺度。仅扩展画布不提高源图实际细节分辨率。

先确认当前工具支持需要的编辑、排版或合成功能。若合成过程会重新生成像素，不能假定身份和衣料被原样保留，必须按新图完整质检。工具不支持合成时交付独立视图、合成规格单和“待合成”状态；不能称已完成整板。拆视图处理仍受原任务剩余返修轮次及预算约束，不为每个视图自动另开两轮。

## 可直接使用的亚洲古风成年女性示例

以下为原创默认设计，并非对原对话未能读取的图片进行复原。可将这一段直接填入通用提示词的“身份锁定”和“服装材质”位置。

```text
同一位约26岁的亚洲古风成年女性，仪态端正，神情平静。偏鹅蛋脸，柔和且清晰的下颌，平直略弯的自然眉，深棕眼睛，适中的眼距，鼻梁自然挺直、鼻尖圆润，唇形清楚但不夸张。暖中性浅肤色，保留颊部轻微血色及细腻皮肤纹理，低覆盖自然淡妆，不使用磨皮滤镜。

黑色长发中分，后上方盘成结构清楚的发髻，余发顺背垂下；一枚哑光玉簪插在角色自身左侧，不佩戴耳饰。每个视图保持同样的发际线、发髻体积与玉簪位置。

米白色交领内衣，外穿低饱和浅青色丝质长衫，领口在角色右侧闭合，袖形舒展但不遮住手。深青色织物腰带系在高腰，结位于角色自身右侧；米白色长裙自然下垂，露出浅色平底布鞋鞋尖。无手持道具。属于原创古风服装设计，不指定历史朝代。

外衫有丝绸柔和的方向性反光与顺重力垂落的细褶，内衣和长裙为偏哑光的棉质织物，有克制的细密织纹，腰带较厚实。领口少量同色刺绣贴附布面，不发光，不形成漂浮的金属花纹。
```

## 负面约束库

按本次任务规格筛选，未启用的布局、视角、背景约束必须删除；例如灰底任务不加入“无背景渐变”等未经要求的限制，单头像任务不加入“缺少视图、裁脚”。优先排除已出现的错误，避免无限加词。无需把痣、雀斑或正常肤色变化一概排除，也不要用“无瑕皮肤”抵消真实纹理。

```text
无动漫、插画、游戏CG、蜡像、塑料皮肤、过度磨皮、均匀颗粒毛孔、油亮面具、过度HDR、锐化光晕、假睫毛团块；无广角畸变、大头短腿、超长四肢、异常腰髋、畸形手指、额外肢体、衣物穿模、悬浮衣摆；无身份漂移、五官换脸、发型变化、服装换色、配饰增减或左右镜像错误；无四分之三侧身冒充左侧面、背面回头、重复正面、缺少视图、多行布局、串栏、裁头裁脚；无场景、文字、水印、边框、地平线、背景渐变、背景或地面投影。
```

## 定向返修模板

```text
以{当前输入图及图片版本}和{本轮身份基准图及基准版本}为基础，遵循角色卡{编号与版本}，只修正{具体列与缺陷}。基准未建立时注明仅依文字角色卡，不虚构图像参考。
维持已通过的{脸部锚点、发型、服装、颜色、构图、其他视图}。
修正后的可观察目标：{例如第三列展示角色自身左侧，鼻尖朝画面左方，肩髋严格侧向，脚底仍与第二、四列对齐}。
不要通过{例如镜像整图、拉伸身体、全局磨皮}实现修正。
修正后先检查目标缺陷，再复查全部适用必验项，以及其他区域、配饰身体左右侧和相邻边界是否退化。
```

执行返修时保留输入、输出和各自质检记录，按 [质检与返修](quality-check.md) 的总体结论与版本选择规则决定保留或回退；提示词中的保留指令不能代替实际复查。

最终交付按 [SKILL.md 的交付规则](../SKILL.md#交付) 组织。仅提供文本时展开所有适用槽位，并标记未执行与待检；本文件的角色卡、版本关联及合成规格单可直接作为交付中的引用，不重复另建一套记录。
